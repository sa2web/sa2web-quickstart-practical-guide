# Sa2web Quickstart and Practical Guide

*Sa2web Quickstart and Practical Guide*는 기업 관리자, IT 운영 팀, 보안 팀, 비즈니스 시스템 소유자, AI 자동화 실무자를 위한 실용적인 한국어 책입니다. 단순한 설치 메모가 아닙니다. Sa2web을 사용하여 기업 웹 접근을 더 안전하고, 더 제어 가능하고, 더 감사 가능하고, 팀 간 인수인계를 더 쉽게 만드는 방법을 설명합니다.

Sa2web 튜토리얼, Sa2web 퀵스타트, 엔터프라이즈 리모트 브라우저 가이드, 클라우드 브라우저 접근 제어, SaaS 계정 거버넌스, 내부 사이트 접근, 브라우저 베스천, 리모트 브라우저 감사, AI 에이전트용 제어된 브라우저 접근을 찾고 있다면, 이 책은 제로 배포에서 팀 준비 사용까지 실용적인 경로를 제공합니다.

## Sa2web이 해결하는 문제는?

전통적인 엔터프라이즈 웹 접근 모델에서 직원들은 보통 SaaS 제품, 비즈니스 백엔드, 공급업체 시스템, 내부 사이트를 로컬 브라우저에서 직접 접근합니다. 이로 인해 지속적인 운영 및 보안 문제가 발생합니다:

- 계정, 쿠키, 세션, 브라우저 환경이 직원 기기에 분산.
- 관리자가 어떤 시스템에 누가 접근할 수 있는지, 어떤 계정이 사용되는지 쉽게 제어 못 함.
- SaaS 자격 증명, 내부 URL, 비즈니스 매개변수, 민감한 페이지 노출 가능.
- 민감한 데이터 복사, 다운로드, 스크린샷, 공유를 중앙에서 제어하기 어려움.
- 계약자, 고객, 임시 사용자, 공급업체, 교차 팀 협업자가 접근 필요할 수 있지만, 원시 사용자명과 비밀번호 넘기는 건 위험.
- 직원이 퇴사, 역할 변경, 프로젝트 완료 시 세션과 접근 흔적 완전 복구 어려움.
- 인시던트 발생 후 관리자는 조사를 위한 재생 가능한 브라우저 증거 부족한 경우가 많음.
- AI 에이전트 비즈니스 페이지 작동 필요하지만 명확한 권한 경계 가진 제어된 브라우저 환경 필요.

Sa2web은 "개인 기기에서 웹 페이지 열기"를 중앙 관리되는 엔터프라이즈 브라우저 접근 프로세스로 바꿔 해결. 접근 진입점, 계정 세션, 브라우저 런타임 환경, 권한 정책, 데이터 보호, 감사 기록을 관리되는 리모트 브라우저 워크스페이스로 이동.

## Sa2web은 어떻게 하는가?

Sa2web 뒤 핵심 아이디어 단순: 사용자 여전히 자기 브라우저에서 페이지 열지만 타겟 사이트 실제로는 제어된 서버 환경에 배포된 리모트 브라우저로 접근됨.

이 아키텍처로 엔터프라이즈 웹 접근 관리 가능한 객체 세트 됨:

- **머신 및 브라우저 인스턴스**: Linux x86_64 서버에서 리모트 브라우저 환경 실행, 실제 접근 동작 처리.
- **클라우드 브라우저**: 사용자에게 독립적 제어된 리모트 브라우저 프로파일 제공, 로컬 기기 차이와 데이터 분산 감소.
- **SaaS 사이트**: 외부 비즈니스 시스템 통합 진입점으로 노출, 관리자 계정 사전 로그인하고 자격 증명 넘기지 않고 직원 승인.
- **워크스페이스**: 사이트 계정, 브라우저 환경, 접근 구성 다중 계정, 다중 매장, 다중 고객, 다중 리전 워크플로 위해 바인딩.
- **내부 사이트**: 직원 관리된 진입점 통해 인트라넷 시스템 접근 가능, 엔드포인트 기기 내부 네트워크 직접 노출 안 함.
- **협업 링크**: 고객, 계약자, 임시 사용자, 배송 시나리오 위해 제어 가능, 만료 가능, 비밀번호 보호된 접근 제공.
- **사용자, 역할, 그룹, 권한**: 통합 승인 모델 통해 사용자, 사이트, 워크스페이스, 내부 사이트, 에이전트, 프록시, 기능 접근 관리.
- **타겟 URL 보호, 워터마크, 민감 콘텐츠 제어**: 실제 URL, 내부 경로, 비즈니스 매개변수, 민감 필드 노출 감소.
- **녹화 및 리플레이**: 감사, 문제 해결, 교육, 책임 위해 핵심 브라우저 접근 프로세스 캡처.
- **사이트 스크립트 및 API 스크립트**: 복잡한 페이지 향상, 데이터 마스킹, 자동화 지원, 비즈니스 시스템 통합.
- **MCP / AI 접근**: Codex, Claude Code, Cursor 및 기타 AI 클라이언트 엔터프라이즈 권한 경계 내 리모트 브라우저 작동 허용.

이 기능들 함께 Sa2web을 엔터프라이즈 브라우저 접근의 컨트롤 플레인으로 만듦. 일일 직원 접근, 임시 협업, 민감 시스템 거버넌스, AI 에이전트 자동화 지원 가능.

## 무엇을 구축하는지 배울 수 있는가?

이 책 읽으면 제로에서 사용 가능한 Sa2web 환경 배포하고 일반적인 엔터프라이즈 접근 거버넌스 루프 완료 가능:

- Sa2web 설치하고 라이선스, 머신, 브라우저, 인증서 구성.
- 클라우드 브라우저, SaaS 사이트, 내부 사이트, 워크스페이스 생성.
- 워크스페이스 사용해 다중 비즈니스 계정과 안정적 브라우저 환경 관리.
- 협업 링크 사용해 외부 사용자 제한적 접근 허용.
- 사용자, 관리자, 역할, 그룹, 권한으로 승인 모델 구축.
- 민감 사이트 URL 보호, 워터마크, 복사/다운로드 제한, 민감 콘텐츠 제어 활성화.
- 중요 비즈니스 접근 녹화 및 리플레이 활성화.
- 복잡한 사이트 페이지 향상, 데이터 마스킹, 자동화 지원 위한 스크립트 작성.
- Sa2web MCP 구성해 AI 에이전트 제어된 계정과 승인된 범위 통해 비즈니스 페이지 접근 가능하게.
- 일반적인 배포, 접근, 인증서, 권한, MCP, 패스키 문제 해결.

## 빌드

```bash
quarto render
```

HTML만 빌드:

```bash
quarto render --to html
```

로컬 미리보기:

```bash
quarto preview
```

출력 디렉토리: `_book/`.

## 소스

## 이미지 및 PDF

`images/` SVG 파일 편집 가능한 아키텍처 다이어그램. `images/screenshots/` 실제 Sa2web 관리자 스크린샷용 예약. 이 프로젝트 제품 스크린샷 조작 안 함.

PDF 출력 XeLaTeX 사용. 사용 가능한 폰트 필요, 또는 TinyTeX 설치 가능:

```bash
quarto install tinytex
```
